and a low-distraction companion device.

## Product promise

The agent can browse, summarize, screenshot, stream, message, post, like, and operate apps on a
virtual desktop. The user can take over at any time. Every irreversible action is represented as
a single explicit intent and gets a fresh approval before execution.
